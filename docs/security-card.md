# 安防宽卡

实现位于 [`frontend/mi-security-card.js`](../frontend/mi-security-card.js)。已按用户调整后的顺序部署到实机环境的旧主题与弧光主题，两款摄像机可实时观看和存储卡回看。0.2.0b6 同时支持猫眼存储卡入口；云端事件仍可独立选择。该卡片需独立配置，不会由集成安装包自动改写用户主题。

卡片横跨两列，旧主题高度 178px，弧光高度 170px。默认显示餐厅、阳台 SVG 场景封面及名称，不取快照、不预加载视频。点击播放同时观看两路，停止或离开即释放；点击单路放大时保留 iframe。录像按钮先停止实时画面，再进入对应设备存储卡回看。暂不包含云台、麦克风或对讲。

使用时，将 JS 放在 HA `www` 目录并添加 module 类型 Lovelace 资源，然后使用以下结构。设备标识必须换成集成选项中实际选中的摄像机 DID，示例 `1`、`2` 是占位值。原生 grid-layout 以外的布局需要按自己的网格设置宽度。

```yaml
type: custom:mi-security-card
variant: arc # classic 为旧主题尺寸
view_layout:
  grid-column: span 2
cat_eye: "3" # 可选：已配置猫眼 DID，占位值需替换
cameras:
  - device: "1"
    name: 餐厅
    scene: dining
  - device: "2"
    name: 阳台
    scene: balcony
```

卡片使用当前 HA 会话签发短期路径，沿用集成既有视频入口。默认静音；不保存账号和视频地址，也不创建第二套接收客户端。测试涵盖手机/桌面布局、默认零请求、晚到签名取消、关闭释放以及真实两路解码。上线后两套主题均验证移动端弹窗在屏内、放大不重建 iframe、录像列表选中对应设备；此次各查到 31 条录像。仅已验证的两款摄像机可作为当前部署依据。

2026-11-06 调整：旧主题以文字标题开头，无前置图标，场景封面采用低饱和配色；弧光使用 36px 圆角底和 25px `mdi:cctv` 图标。两套播放按钮均只显示播放/停止图标，配色随卡片风格。弧光安防卡位于页脚说明之前。放大弹窗根据视频实际比例计算宽高，避免竖屏大面积黑边；录像入口区分 `source=sd`，不会误选同设备云录像。
