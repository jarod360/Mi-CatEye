# 安防宽卡

实现位于 [`frontend/mi-security-card.js`](../frontend/mi-security-card.js)。已按用户调整后的顺序部署到实机环境的旧主题与弧光主题，两款摄像机可实时观看和存储卡回看。0.2.0b6 支持猫眼存储卡，但安防宽卡只展示两台摄像机，不提供门口录像按钮。该卡片需独立配置，不会由集成安装包自动改写用户主题。

卡片横跨两列，旧主题高度 178px，弧光高度 170px。默认显示餐厅、阳台图标封面及名称，不取快照、不预加载视频。点击播放同时观看两路，停止或离开即释放；点击单路放大时保留 iframe。录像按钮先停止实时画面，再进入对应设备存储卡回看。暂不包含云台、麦克风或对讲。

使用时，将 JS 放在 HA `www` 目录并添加 module 类型 Lovelace 资源，然后使用以下结构。设备标识必须换成集成选项中实际选中的摄像机 DID，示例 `1`、`2` 是占位值。原生 grid-layout 以外的布局需要按自己的网格设置宽度。

```yaml
type: custom:mi-security-card
variant: arc # classic 为旧主题尺寸
view_layout:
  grid-column: span 2
cameras:
  - device: "1"
    name: 餐厅
    scene: dining
  - device: "2"
    name: 阳台
    scene: balcony
```

卡片使用当前 HA 会话签发短期路径，沿用集成既有视频入口。默认静音；不保存账号和视频地址，也不创建第二套接收客户端。测试涵盖手机/桌面布局、默认零请求、晚到签名取消、关闭释放以及真实两路解码。上线后两套主题均验证移动端弹窗在屏内、放大不重建 iframe、录像列表选中对应设备；此次各查到 31 条录像。仅已验证的两款摄像机可作为当前部署依据。

2026-11-06 调整：旧主题以文字标题开头，无前置图标，封面使用左下四分之一圆色块与餐具、衣架大图标，沿用对应主题配色；弧光使用 36px 圆角底和 25px `mdi:cctv` 图标。两套播放按钮均只显示播放/停止图标，配色随卡片风格。弧光安防卡位于页脚说明之前。放大弹窗根据视频实际比例计算宽高，避免竖屏大面积黑边；录像入口区分 `source=sd`，不会误选同设备云录像。

最终封面按主题房间卡风格统一为四分之一圆加大图标：旧主题紫色餐具、青绿色衣架，弧光采用柔和金色与紫色。保留安防整体尺寸，默认不取流；手机实时对讲按用户安排延后。

按最终要求：安防标题栏仅保留播放按钮；两路封面使用沙发和窗景图标，不再使用餐具、衣架。从任意设备进入录像页时，设备和来源列表只保留 URL 指定的设备及来源；录像总入口仍可选择全部已配置设备。

最终图片版：旧主题封面改为专门生成的客厅沙发、阳台窗景 WebP 插画，去掉圆形底色与大图标；弧光维持图标式封面。两张图片压缩后内嵌于 JS，无外部图片服务依赖，不取真实摄像机快照。

最终更正：旧主题使用简洁实色平面图形，餐厅为餐桌椅与吊灯，阳台为窗户与绿植；紫色和青绿色配色，无圆形底色。已移除此前生成的写实封面引用，弧光维持原样。

弧光封面已恢复最初的餐桌、阳台窗景 SVG 简画及蓝绿淡底（取自 086df63 的原始图形），不是沙发或衣架图标；旧主题保留紫色餐桌椅与青绿色窗景。
