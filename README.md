# Mi-CatEye

面向 Home Assistant 的独立小米猫眼集成，目标是将猫眼事件、状态与按需视频整合到一个安装包，减少对完整 Xiaomi Home 集成及单独 go2rtc 加载项的依赖。

**当前处于开发阶段，尚无可安装发行版。请勿据此卸载现有集成或切换正在使用的门铃流程。**

## 目标范围

- 首先支持 `loock.cateye.v02`，其他型号尚未验证。
- 接收按铃事件、读取电量及在线状态。
- 三端共享同一条 Xiaomi/MISS 视频会话，按需启动，保留原始音轨能力。
- 电视原始 H.265、小爱屏幕播放，以及 HA 手机通知与视频查看。
- 在集成中管理精简媒体核心，不要求额外安装完整 go2rtc 加载项。

这是云端鉴权和云端事件集成，不能承诺完全离线运行。事件 OAuth 与视频账户鉴权使用不同凭据，目前不能承诺一次授权覆盖两者。

## 开发状态

候选代码正在完成 Home Assistant 适配、媒体核心打包和迁移验证。当前在线环境保持原有版本；本仓库建立不代表已切换设备。

精简媒体核心的二进制体积有所下降，但尚未完成实际运行内存对比，不能据此承诺内存降幅。录像下载迁移仍待完成。

后续发行版将明确给出支持的平台、安装方式、配置步骤和回退方法。发布前不提供 HACS 一键安装承诺。

## 隐私与接口

账号凭据只保存在用户的 HA 私有配置中，不应提交到本仓库。媒体管理 API 和 RTSP 仅监听回环地址；外部视频访问应经过 HA 身份验证或短期路径签名。

请勿在 Issue 中上传账号密码、令牌、带签名的视频地址、完整配置备份或家庭画面。
